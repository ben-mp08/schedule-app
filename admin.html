การประปานครหลวง (กปน.)

กลับหน้าหลัก

🔧 ตั้งค่า API

💡 URL นี้จะถูกบันทึกใน localStorage เพื่อใช้ในครั้งถัดไป

📤 อัพโหลดไฟล์ข้อมูล

รองรับไฟล์ประเภท:

Excel (.xlsx, .xls) CSV (.csv)

คลิกหรือลากไฟล์มาที่นี่

รองรับไฟล์ Excel และ CSV

ตัวอย่างข้อมูล (5 แถวแรก)

📋 คำแนะนำ

1

ตั้งค่า Google Apps Script URL

ใส่ URL ที่ได้จากการ Deploy Google Apps Script (ดูคู่มือใน SETUP_GUIDE.md)

2

เตรียมไฟล์ข้อมูล

ไฟล์ Excel หรือ CSV ต้องมีคอลัมน์:
id, task, startDate, endDate, duration, responsible, department, category, status, progress

3

อัพโหลดไฟล์

คลิกหรือลากไฟล์มาที่กรอบสีเทา ระบบจะแสดงตัวอย่างข้อมูล

4

ตรวจสอบและยืนยัน

ตรวจสอบตัวอย่างข้อมูล แล้วกดปุ่ม "อัพโหลดข้อมูลไปยัง Google Sheets"

ข้อควรระวัง:

  • การอัพโหลดจะแทนที่ข้อมูลทั้งหมดใน Google Sheets
  • แนะนำให้สำรองข้อมูลก่อนอัพโหลด
  • วันที่ควรอยู่ในรูปแบบ YYYY-MM-DD (เช่น 2024-01-15)
